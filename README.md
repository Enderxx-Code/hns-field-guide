# Heart & Soul Field Guide

An unofficial, phone-friendly guide to Pokémon Heart & Soul 2.0.6, built from the [official documentation](https://pokemonhns-development.github.io/pokehns-expansion-documentation/index.html). Heart & Soul is made by the [Heart & Soul team](https://github.com/PokemonHnS-Development/pokehns-expansion).

Open it in Safari and use Share > Add to Home Screen to run it full-screen; it works offline after the first visit.
